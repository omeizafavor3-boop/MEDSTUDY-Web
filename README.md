# MEDSTUDY Website Starter

## Publish using GitHub Pages
1. Extract this ZIP.
2. In your GitHub repository choose Add file → Upload files.
3. Upload index.html, manifest.webmanifest, sw.js and README.md to the repository root.
4. Commit to main.
5. Open Settings → Pages.
6. Choose Deploy from a branch, branch main, folder /(root), then Save.
7. Open the Pages URL GitHub displays after deployment.

## Included
Responsive mobile dashboard, six 100L course entries, topic outlines, sample quiz with explanations, progress stored in browser, lab areas, PDF tutor placeholder and basic offline app shell.

## Not yet included
